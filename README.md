# DelftBlue intro

This repository contains follow-along examples from the DelftBlue part of the HPC intro course. 

Clone it into your home directory on DelftBlue using

```bash
git clone https://gitlab.tudelft.nl/diam/delftblue-intro.git
```

Every exercise is accompanied with a README.md file with instructions.

Examples include:

- Hostname from multiple nodes, to illustrate how resources request and allocation works
- Julia, to illustrate how using a software package form the software stack works
- Python ASE, to illustrate how you can install your own packages
- Bonus: MPI/OpenMP/CUDA example to illustrate how parallelism/acceleration works
- Bonus: PyTorch example to illustrate how a typical GPU job works
